# 📁 File Sharing System

A full-stack file upload and sharing system built using React, Node.js, and MongoDB.  
Users can upload files and share them securely using a 4-digit PIN.

---

## 🚀 Features

- 📤 Upload files (drag & drop + file selector)
- 📥 Download files using PIN
- 🔢 Random 4-digit PIN generation
- 📊 Upload progress bar with percentage
- ⏳ File auto-expiry (1 hour)
- 🌐 Cross-device sharing over local network

---

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **Backend:** Node.js + Express.js  
- **Database:** MongoDB  
- **File Handling:** Multer
